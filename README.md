# Bulk change: case study prototype

A clickable concept prototype for a product case study: changing many employee records at once (comp cycles, reorgs, office moves) in an HR platform, and propagating the change to payroll, benefits and connected apps.

- Static site: `index.html` + `app.js`, plain HTML, CSS and JavaScript. No build step, no backend.
- Metzhand and everyone in it are fictional. Data is generated in the browser.
- Modules: Bulk change, Segments (dynamic rules or static lists from conditions or a CSV upload), People.
- Presentation pages: `approach.html`, `propagation.html`. The Demo controls button switches company size and shows the reasoning behind each element.
